\section*{Research Highlights}

\begin{itemize}
  \item One read operator over atom spaces covers attention, retrieval, and MoE routing
  \item A Lipschitz insertion condition and an exact tail certificate are shown to be far too loose in practice
  \item Anti-atom cancellation is exact but collapses under key perturbations of order 0.05
  \item Held-out ROC calibration lifts CounterFact-500 paraphrase activation from 38\% to 53\%
  \item Matched GRACE run: 99--100\% rewrite efficacy but 0--6\% paraphrase activation on GPT-2
\end{itemize}
